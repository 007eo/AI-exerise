AI刷（爱刷）使用说明

一、启动软件
1. 解压压缩包。
2. 打开文件夹“AI刷（爱刷）”。
3. 双击“AI刷（爱刷）.exe”启动软件。

二、导入题库
1. 在“题库”页面点击导入文件。
2. 支持 doc、docx、pdf 文件。
3. 导入时会显示等待和进度提示，请等待解析完成。
4. 如果文件内容不规范、答案缺失、PDF 无法正常提取文字，软件会给出提示。

三、开始练习
1. 选择题库后进入“练习”页面。
2. 可选择背题模式或答题模式。
3. 可选择顺序出题或随机出题。
4. 范围选择“全部”时练习整套题；选择“部分”时，在题目列表中点击题目勾选要练的题。

四、背题模式
1. 每题作答后点击“提交本题”。
2. 软件立即显示本题答案和解析。
3. 选择题、判断题等客观题答错会自动进入错题本。
4. 简答题等主观题显示答案后，需要手动点击“已掌握”或“未掌握”。
5. 主观题点击“未掌握”后会进入错题本，同一题只能判断一次。

五、答题模式
1. 做题过程中可以点击上一题、下一题，也可以通过答题卡跳转。
2. 点击交卷后，如果还有未答题，软件会询问是否继续提交。
3. 直接提交后，未答题会在结果中显示为“未回答”。
4. 提交后可查看正确率、用时、错题和解析。

六、错题本
1. 客观题答错会自动加入错题本。
2. 主观题标记“未掌握”后加入错题本。
3. 在错题本中可以查看原题、答案和解析，也可以更新掌握状态。
4. 选择一条错题后点击“错题练习”，可练习该题库内全部未掌握错题，流程类似背题模式。
5. 错题练习中，客观题答对后会自动更新为“已掌握”；主观题仍由用户选择“已掌握”或“未掌握”。

七、注意事项
1. 扫描版 PDF 或图片型 PDF 的识别效果取决于本机 OCR 环境。
2. doc 文件导入可能依赖本机安装的 LibreOffice / soffice。
3. 题库文档格式越规范，识别效果越稳定。建议题目、选项、答案、解析使用清晰标记。
4. 软件会在程序目录下自动生成 data 文件夹保存题库、练习记录和错题数据，请不要随意删除。
